# PayPilot One – The AI-Powered Business, Commerce & Payment Ecosystem

PayPilot One is a unified, enterprise-grade digital business ecosystem that connects five distinct domains—Business Management, E-Commerce, Philanthropic Fundraising, Automated Invoicing, and Central Multi-Agent AI Operations—into a single coherent platform powered by React, Tailwind CSS, Supabase, PayPal Sandbox, and Google Gemini.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> The following architectural decisions were confirmed in Phase 1 clarification:
> - **Backend Database & Connectivity**: Direct live Supabase connection with an integrated Connection & Setup Wizard, pre-validating URL and anon/service keys, combined with a SQL Migration Script tab for instant copy-pasting into the Supabase SQL editor.
> - **Industry Preset**: Pre-configured for **Tech SaaS, Cloud Tools, and Software Services** (API subscriptions, developer tooling, cloud credits, digital microservices).
> - **AI Copilot Interaction Style**: **Visual interactive action cards with confirmation modals** for all sensitive operations (invoice generation, payment capture, payment reconciliation, reminder drafting) before any database modification occurs.

## 1. Overview & Core Concept

### What It Does
PayPilot One bridges fragmented financial workflows. A transaction in the online store (AgentCart AI) immediately feeds revenue analytics (PayPilot AI). An invoice generated by natural language (InvoiceMind AI) is tracked alongside customer purchase histories. Crowdfunding goals (GiveAI) reflect in overall financial statements. At the center sits **PayPilot Copilot**, an orchestrated multi-agent network capable of executing cross-module analytical queries, preparing transactional drafts, and providing executive business intelligence.

### Target Audience & Persona
- **Founders & SaaS Operators**: Need a single cockpit for subscription sales, bespoke client invoices, platform donations, and automated reminders.
- **Finance & Operations Leads**: Need unified reconciliation between PayPal payments, bank transactions, and customer invoices without manual spreadsheet bookkeeping.
- **E-Commerce & Digital Commerce Managers**: Need AI-driven catalog recommendations, cart optimization, and verifiable sandbox checkout.

### Key Value
- **Zero-Silo Financial Flow**: All 5 modules share one PostgreSQL database, unified authentication, unified audit logs, and synchronized transaction records.
- **Enforced Human-in-the-Loop AI**: AI agents can draft, analyze, query, and recommend, but cannot execute financial changes without explicit human modal approval.
- **Audit-Ready Traceability**: Every sensitive state change, AI action, and PayPal webhook event is permanently recorded in an immutable audit ledger.

  - Collapsible, high-contrast sidebar ($260\text{px}$) with dedicated tabs for Overview, PayPilot AI, AgentCart AI, GiveAI, InvoiceMind AI, PayPilot Copilot, Transactions, Reports, and System Settings.
- **Color Discipline (60-30-10 Rule)**:
  - 60% Canvas: Neutral background (`bg-slate-50 dark:bg-slate-950`).

  - No static pill badges. Metadata (invoice due dates, SKU codes, categories) uses unboxed typographic separation (`Paid · Due Nov 15 · INV-2026-004`).

## 3. Key Product Decisions & Trade-Offs

### Decision 1: Live Supabase Backend with Guided Setup & Schema Migrations
- **Chosen Approach**: Direct integration with Supabase JavaScript Client (`@supabase/supabase-js`). The app presents a non-intrusive Connection Drawer and pre-formatted SQL Migration runner that creates all 22 tables, foreign keys, and RLS policies on the user's project, while also providing pre-seeded SaaS demo data immediately upon initialization.
- **Why**: Allows instant live testing while maintaining zero hardcoded secrets. Ensures full compliance with production PostgreSQL schemas and Row Level Security.

### Decision 2: Server-Side Gemini API Proxy with Structured Specialist Agents
- **Chosen Approach**: Centralized backend route (`/api/copilot/chat` via Express/Node.js) using the `@google/genai` TypeScript SDK (`gemini-3.8-flash`). The backend maintains system prompts for the Master Orchestrator and 5 specialist agents (Business, Shopping, Donation, Invoice, and Payment Operations).
- **Why**: Protects the `GEMINI_API_KEY` on the server, prevents client-side tampering, and enforces strict JSON schemas for tool calling and approval requests.

### Decision 3: PayPal Sandbox Integration Architecture
- **Chosen Approach**: Full standard PayPal sandbox flow with client-side approval widget backed by server-validated order creation and server-side capture endpoints (`/api/paypal/create-order`, `/api/paypal/capture-order`).
- **Why**: Prevents client-side price falsification. The backend calculates order totals from authoritative database records before calling the PayPal Orders API.

### Module Breakdown & Feature Matrix

#### 1. PayPilot AI (Business Intelligence & Operations)
- **Executive KPI Cards**: Real-time Total Revenue, Orders, Active Customers, Software Products, Overdue Invoices, and Growth Rate.
- **Revenue Analytics**: Interactive Recharts visualizations (Daily Revenue, Revenue by Plan/Product, Customer Acquisition Cohorts).
- **Customer Directory**: Full CRUD with contact info, lifetime value, purchase history timeline, and invoice history.
- **Product Catalog Management**: Manage SaaS tiers, cloud licenses, unit prices, SKUs, and stock limits.

#### 2. AgentCart AI (AI Shopping & Sandbox Checkout)
- **Tech SaaS Marketplace**: Browse cloud instances, developer licenses, analytics subscriptions, and API credit bundles.
- **Natural Language Product Discovery**: AI assistant filtering by budget (e.g., "Find an API monitoring tool under $100/mo").
- **Cart & Server-Side Inventory**: Cart drawer with price calculation, tax computation, and live stock validation.
- **PayPal Sandbox Checkout**: Instant order creation and sandbox payment capture.

#### 3. GiveAI (Crowdfunding & Impact Donations)
- **Campaign Hub**: Active campaigns (e.g., "Open Source Dev Grants", "AI Accessibility Initiative") with progress meters and countdowns.
- **Donation Flow**: Custom donation amounts, gift matching calculations, and verified PayPal Sandbox processing.
- **AI Campaign Assistant**: Generates compelling, fact-checked project descriptions and impact summaries.

#### 4. InvoiceMind AI (Intelligent Invoicing)
- **Natural Language Invoice Drafting**: Users type "Create an invoice for Acme Corp for 10 Cloud Licenses at $150 each", AI drafts the line items and tax, then prompts for visual confirmation.
- **Visual Invoice Builder**: Line item editor, discount handling, auto tax computation, and status lifecycle (Draft, Issued, Paid, Overdue).
- **Client-Side PDF Generator**: Instant high-resolution downloadable invoice PDFs with business branding, payment details, and breakdown.

#### 5. PayPilot Copilot (Central Intelligence & Multi-Agent Network)
- **Agent 1: Business Agent**: Analyzes revenue trends, high-churn customers, and product velocity.
- **Agent 2: Shopping Agent**: Recommends SaaS bundles and handles order lookup.
- **Agent 3: Donation Agent**: Summarizes campaign velocity and donor engagement.
- **Agent 4: Invoice Agent**: Drafts invoices and prepares overdue payment reminders.
- **Agent 5: Payment Operations Agent**: Reconciles transactions against PayPal orders.
- **Agent 6: Master Orchestrator**: Identifies intent, invokes authorized database tools, formats response cards, and displays confirmation modals for sensitive actions.

## 5. Step-by-Step Implementation Sequence

1. **Step 1: Dependencies & Base Setup**: Install `react-router-dom`, `@supabase/supabase-js`, `recharts`, `jspdf`, `canvas-confetti` (for successful payments).
2. **Step 2: Server Architecture (`server.ts`)**: Build full-stack Express server integrating Vite middlewares, Gemini 3.8 Flash multi-agent tool pipeline, PayPal sandbox endpoints, and secure API routing.
3. **Step 3: Database & Supabase Migrations (`/supabase/migrations/`)**: Implement full SQL schema with 22 tables, foreign keys, timestamps, indexes, RLS policies, and seed data.
4. **Step 4: Design System & Shared Layout**: Build navigation sidebar, top bar contract with dual-theme toggle, KPI cards, breadcrumbs, and notification system.
5. **Step 5: PayPilot AI Module**: Business dashboard, customer CRM, product management, and analytics charts.
6. **Step 6: AgentCart AI Module**: Product catalog, cart state, inventory checking, and PayPal Sandbox modal.
7. **Step 7: GiveAI Module**: Campaign creation, campaign cards, donation checkout, and AI copy generation.
8. **Step 8: InvoiceMind AI Module**: Invoice generator, status tracker, AI natural language drafting with review modal, and PDF export.
9. **Step 9: PayPilot Copilot**: Conversational interface with 5 specialist agent tags, tool calling, interactive approval cards, and audit log viewer.
10. **Step 10: Compilation & Final Verification**: Run `compile_applet` and `lint_applet` together to verify zero syntax errors and complete responsiveness.
